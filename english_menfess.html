Rules

Mohon baca dulu sebelum kirim menfess supaya autobase tetap nyaman untuk belajar dan ngobrol seputar bahasa Inggris.

  • Dilarang OOT dan spam.
  • Khusus Sabtu & Minggu boleh OOT tapi WAJIB pakai bahasa Inggris.
  • No hate speech is allowed.
  • Dilarang berjualan / jual-beli / promosi / menyebarkan kode referral / giveaway.
  • Dilarang softselling.
  • Dilarang mengirim menfess berisi konten 18+ (Pornografi) / SARA / politik / kebencian / teror / rasisme / membuat keributan.
  • Dilarang menyebar privasi orang lain tanpa izin.
  • Dilarang mengirim menfess bertagar / hashtag.
  • Dilarang reply OOT / jualan / hashtag / fancam / promosi thread sendiri.
  • Dilarang mengirim link selain link dari twitter.
  • Dilarang kirim menfess HOAX atau yang belum pasti kebenarannya.

Sanksi

  • 1x melanggar = PERINGATAN
  • 2x melanggar = BLOCK
